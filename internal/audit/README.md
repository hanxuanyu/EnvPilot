# audit

操作审计模块：记录关键管理动作和连接器行为，当前已经接入资产、凭据和中间件连接器链路，并提供统一查询接口。

## 当前覆盖范围

- 资产：创建、更新、删除
- 凭据：创建、更新、删除、明文查看
- 连接器：连接测试、SQL 执行、Redis 命令执行、MQ 消息发送

## 目录结构

- `model/` - 审计日志数据模型
- `repository/` - 查询与写入
- `service/` - 审计记录封装与分页查询
- `api/` - Wails 绑定层

## 说明

- 审计内容会尽量记录请求摘要和结果摘要，而不是无差别持久化敏感明文。
- 对 MQ 消息当前只记录主题、路由键、Header 数量和消息体长度，不直接记录完整消息体。
- 如果后续扩展到命令执行、配置系统和健康检查，可沿用同一 `AuditService` 继续接入。
